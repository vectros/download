Verify the download

Every release has a CHECKSUM file signed with the VectrOS key, like Fedora's. Check the signature, then the ISO. Put both files next to the ISO.

VectrOS-2026.10.10.1-x86_64-CHECKSUM VectrOS signing key 
gpgv --keyring ./vectros.gpg VectrOS-2026.10.10.1-x86_64-CHECKSUM
sha256sum --ignore-missing -c VectrOS-2026.10.10.1-x86_64-CHECKSUM

The first command must say Good signature from "VectrOS package signing"; the second, vectros-2026.10.10.1-x86_64.iso: OK (it also warns about the signature's lines; that is expected). The key's fingerprint is 6287 B50E 3F78 BA61 A4E2 8D19 6ADA AC27 044C C53D.

Write it to a USB stick

Use a stick of 8 GB or more. Everything on it is erased.

  • Fedora Media Writer (Windows, macOS, Linux): choose Select .iso file, then the VectrOS ISO.
  • Rufus (Windows): when asked, choose DD Image mode.
  • balenaEtcher (Windows, macOS, Linux).
  • Linux terminal: sudo dd if=vectros-2026.10.10.1-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync, with /dev/sdX your USB stick.

Install

  1. Start the computer from the USB stick (often F12, F10 or Esc at power-on). VectrOS starts in UEFI mode.
  2. Try the live desktop, then choose Install VectrOS in the launcher.
  3. Pick the disk, name the computer, create your account, and choose whether to encrypt the disk. The whole disk is erased; the install works offline.

What you need

  • A 64-bit PC with UEFI, 8 GB of memory (16 GB for local AI models) and a disk of 20 GB or more.
  • Secure Boot off: the AIOS kernel module is not signed yet.
  • An internet connection for updates and to download AI models; the install itself needs none.

Mirrors

Files keep Fedora's layout, so a mirror can copy them as they are: releases/<version>/x86_64/iso/. To run a mirror, open an issue in vectros/download.
